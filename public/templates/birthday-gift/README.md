# 🎈 Interactive Birthday Gift

A cinematic, interactive birthday website built with Vanilla JavaScript, HTML5 Canvas, CSS3, and GSAP.

## ✨ Features

- **Interactive Archery Mechanism**: Smooth bow-and-arrow drag/release gesture using pointer events.
- **Dynamic Heart Burst & Kinetic Typography**: Smooth GSAP timelines driving text hinges and particle effects.
- **Canvas Heart Blossom Tree**: Custom 2D canvas particle engine rendering a blooming heart-shaped tree with falling petals.
- **Fully Responsive**: Optimized for desktop and mobile viewports.

## 🚀 Quick Start

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/saklincodes/Birthday-Gift.git
   cd Birthday-Gift
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🛠️ Built With

- **HTML5 / CSS3**: Custom design tokens and responsive layout.
- **JavaScript (ES Modules)**: Modern ES6+ syntax.
- **GSAP (GreenSock Animation Platform)**: Animation timeline orchestration.
- **HTML5 Canvas 2D**: Procedural tree growth & particle system.
- **Vite**: Ultra-fast build tool.
