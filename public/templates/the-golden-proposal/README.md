# 💍 The Golden Proposal

A luxury, interactive romantic web experience built with Vanilla JavaScript, Web Audio API, and modern CSS layout systems. Features a seamless single-stage interactive flow, custom audio synthesis, dynamic dialogue progression, and responsive animations.

## ✨ Features

- **Single-Stage Architecture**: Seamless view state transitions without scrollbars or page reloads.
- **Procedural Audio Synthesizer**: Built using the Web Audio API to deliver custom musical chimes and celebration fanfares without external audio file dependencies.
- **Interactive Storytelling**: Step-by-step dialogue progression with custom reply input and interactive suggestion pills.
- **Responsive Choice Mechanics**: Dynamic dodging behavior for alternative choices with custom contextual tooltips.
- **Custom Design System**: Soft vanilla cream and blush pink palette built with CSS custom properties (`var(--tokens)`), smooth GPU-accelerated keyframes, and tailored typography.
- **Ambient Visual Effects**: Procedural rose petal generation, particle bursts, and canvas-free lightweight DOM animations.

---

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5
- **Styles**: Modern CSS3 (CSS Variables, Flexbox, Keyframe Animations, Glassmorphism)
- **Scripting**: ES6+ Vanilla JavaScript (DOM Manipulation, Web Audio API, IntersectionObserver)
- **Typography**: Google Fonts (*Cinzel Decorative*, *Playfair Display*, *Dancing Script*, *Nunito*, *Outfit*)

## 🚀 Quick Start

### Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/saklincodes/The-Golden-Proposal.git
   ```

2. **Navigate to the directory**:
   ```bash
   cd The-Golden-Proposal
   ```

3. **Run locally**:
   - Open `index.html` directly in any web browser, or use Live Server extension in VS Code.
